# baw-clothing-frontend

# Recriação do site BAW Clothing

Projeto de front-end desenvolvido durante meu período de treinamento com os desenvolvedores da BAW Clothing.

O objetivo foi recriar visualmente o site da empresa utilizando HTML e CSS. Usei o site original como referência, mas construí a estrutura e a estilização do projeto do zero.

## Sobre o projeto

O desenvolvimento levou aproximadamente um a dois meses e resultou em um protótipo com cinco páginas:

* Página inicial
* Vestuário
* Acessórios
* Calçados
* Bawlet

O projeto possui aproximadamente 1.600 linhas de HTML e CSS, incluindo menus, submenus, efeitos de hover, banners, categorias de produtos e rodapé.

## Principais desafios

As partes mais difíceis foram criar os efeitos de hover dos menus e centralizar corretamente algumas imagens. Esses detalhes pareciam simples visualmente, mas exigiram vários testes e ajustes no CSS até que os elementos se comportassem como eu esperava.

Durante o desenvolvimento, fui acompanhado pela equipe de desenvolvedores da BAW. Também recebi ajuda pontual do Chris em alguns trechos de código relacionados aos efeitos de hover e ao posicionamento das imagens.

## O que aprendi

Esse projeto me ajudou a transformar conhecimentos teóricos em algo visual e funcional. Aprendi mais sobre organização de páginas, Flexbox, posicionamento de elementos, reutilização de estilos e resolução de problemas no CSS.

O resultado foi uma recriação educacional do front-end da BAW e uma das minhas primeiras experiências construindo um projeto com várias páginas.

## Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* GitHub

## Aviso

Este projeto foi desenvolvido exclusivamente para fins de aprendizado durante meu treinamento. Não é o site oficial da BAW Clothing e não possui finalidade comercial. As marcas e imagens utilizadas pertencem aos seus respectivos proprietários.
